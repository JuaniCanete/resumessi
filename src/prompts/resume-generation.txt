# resumessi — Resume Generation Prompt
# 
# This prompt can be used in two ways:
# 1. Manually: Fill in your info and give this file to an AI assistant to generate resume-data.json
# 2. Automatically: Run `node generate-resume.js` to use AI to parse raw input
#
# IMPORTANT: This generates the src/resume/output/resume-data.json file that public/main.html reads at startup.
# The HTML is not going to show any data until src/resume/output/resume-data.json is generated — everything comes from the JSON.
#
# ================================================================================
# SECTION 1 — SYSTEM INSTRUCTION (for AI consumption)
# ================================================================================
#
# You are a resume data extraction and formatting assistant. Your task is to parse
# the raw user input below and output a valid JSON object matching the schema at:
# Use the schema in src/resume/output/resume-data.json as the source of truth
#
# RULES:
# - Output ONLY valid JSON, no markdown, no explanation
# - Use the exact same structure as src/resume/output/resume-data.json
# - For experience bullets, preserve HTML formatting like <strong> for emphasis
# - Expert skills get "expert": true, others get false
# - If any section is missing data, use empty arrays or null values
#
# ═══════════════════════════════════════════════════════════════
# IDENTITY PRESERVATION — STRICT RULES
# ═══════════════════════════════════════════════════════════════
# - Extract the candidate's name VERBATIM from the input text. Do NOT paraphrase, normalize, "correct", or invent a name.
# - If the input text says "Juani Cañete", the output basics.name MUST be "Juani Cañete".
# - You are FORBIDDEN to generate output for any placeholder name like "John Doe", "Jane Doe", "Alex Johnson", or similar.
# - If no name is visible in the input, output an empty string "" for basics.name — NEVER invent a fake name.
#
# ═══════════════════════════════════════════════════════════════
# SELF-VALIDATION (before outputting)
# ═══════════════════════════════════════════════════════════════
# Verify ALL of the following before returning:
# □ basics.name is the EXACT name from the input (VERBATIM copy — no paraphrasing, no invented names).
# □ No invented or assumed personal details (addresses, phone numbers, dates) appear in any field.
# □ No placeholder examples like "keyword1", "Your Name", "John Doe", or "Alex Johnson" appear in output.
# □ JSON is valid and parseable via JSON.parse().
# □ All required fields present.
# □ No markdown (**), em dashes (--), or formatting artifacts inside text strings.
# □ Expert flags set correctly.
#
# ================================================================================
# SECTION 2 — USER INPUT (fill in your information below)
# ================================================================================
#
# --- Personal Info ---
# Full Name:
#
# Professional Title / Headline:
#
# Email:
#
# Phone:
#
# Location (City, Province/State, Country):
#
# LinkedIn URL:
#
# GitHub URL:
#
# Profile Photo (filename in resumessi/ folder):
#   photo.jpg
#
# --- Professional Summary (2-4 sentences) ---
#
#
# --- Work Experience (most recent first. For each role:) ---
# Job Title:
# Company:
# Start – End Date:
# Bullet points (each on a new line starting with -):
#   - 
#
# --- Skills (grouped by category. Mark experts with *EXERT*) ---
# Category Name:
#   *EXPERT* Skill Name, Skill Name, Skill Name
#
# --- Tech Stack ---
#
# --- Languages ---
# Language — Level
#
# --- Education ---
# Degree:
# Institution:
# Year:
#
# --- Certifications ---
# Title:
# Issuer:
# Date:
# Duration (optional):
# Verification URL:
#
# --- Tech Talks ---
# Title:
# Event:
# URL:
#
# ================================================================================
# SECTION 3 — OUTPUT SCHEMA REFERENCE
# ================================================================================
#
# The expected output is a JSON object with these top-level keys:
#   basics       - { name, title, email, phone, location, photo, linkedin, github }
#   summary      - string
#   experience   - [{ title, company, date, bullets[] }]
#   skills       - { "Category": [{ name, expert }] }
#   techStack - string (HTML allowed)
#   languages    - [{ name, level }]
#   education    - [{ degree, institution, year }]
#   talks        - [{ title, event, url }]
#   certifications - [{ title, issuer, date, duration, url }]
#
# ================================================================================
# END OF PROMPT
